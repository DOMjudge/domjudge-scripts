This page lists tools and facilities that can work with DOMjudge. They are not in all cases maintained by the DOMjudge team.

Creating problemsets

Checktestdata
checktestdata is a program to syntactically verify testdata according to a grammar file. It also supports generating testdata based on a specification.
BAPCtools & Kattis problemtools
are similar tools that help creating and developing problems following the problem package format, which DOMjudge can import (but not supporting all options). The aim of these tools is to run all necessary compilation, validation, and testing commands while working on an ICPC-style problem. This helps enforce consistency and quality of problems. BAPCtools is currently the more feature-rich and actively maintained of the two.
Polygon2DOMjudge
is a tool that converts problem packages exported from the Codeforces Polygon Platform into the DOMjudge Problem Package format.

Contest as a service

Cloudcontest
DOMjudge is free to download and run yourself. Do you prefer a hosted installation of DOMjudge, take a look at cloudcontest.org. They offer a fully online hosted contest that your teams can access over the internet. It is also possible to run the server in the cloud and your judgehosts locally.

Scoreboard resolvers and other contest tools

ICPC Tools
ICPC Tools is a set of (free to use) tools that can work with a CLICS compatible API, like DOMjudge provides. It has a scoreboard display and resolver, balloons utility and various other presentation tools.
DOMjura
(DOMjudge Results Application) is a scoreboard resolver, which can read the DOMjudge API after a contest and present the results. This is currently unmaintained.
Carnifex
presents a live scoreboard and is a scoreboard resolver. It has a server component where various display clients can connect to. This is currently unmaintained.
LightDM CCS autologin
makes it possible to automatically log in to team machines when the contest starts in DOMjudge. This is useful to keep problem data secret and to make sharing credentials easier on the organizer.

DOMjudge for teaching

DOMjudge is focused on being a contest system for short-running contests. Some people use DOMjudge for teaching and long-running contests. We are happy to include features useful for such other scenarios in DOMjudge when they do not complicate the UI and code too much. Since not everything will make it into our releases, we link here to some extensions to help with this use case.

Isolate
is an alternative to runguard from DOMjudge for creating a sandbox to run submissions in.
DOMtutor
provides a set of scripts to make it easier to use DOMjudge in a teaching setting.
